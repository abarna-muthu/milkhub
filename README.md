# MilkHub — Milk Collection & Dairy Management CRM

> **Developed by Gen Z Neural-X**

MilkHub is a modern, full-stack Dairy Operations & Milk Collection Management Platform built with React, TypeScript, Tailwind CSS, Express, and Vite.

## Features
- **Intake & Collection**: Real-time morning/evening collection recording with automatic Fat/SNF calculations and instant pricing.
- **Supplier Directory**: Complete supplier management with ledger, balances, and quick intake shortcuts.
- **Payments & Settlements**: Period settlements, payout slips, and PDF exports.
- **WhatsApp Integration**: Instant settlement notifications and payment reminders in Tamil & English.
- **Strict Role-based Security**: Admin and Collection Staff access controls.
- **Pure Bilingual Support**: Instant 1-click toggle between 100% pure English and 100% pure Tamil.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone <repo-url>
cd "MILK CRM"

# Install dependencies
npm run install:all
```

### Running Locally
```bash
# Start backend server (port 5000)
npm run dev:server

# Start frontend application (port 5173)
npm run dev:client
```
